# Brainrot Death Messages

A lightweight Minecraft plugin that replaces boring death messages with chaotic Italian brainrot inspired lines for falls, mobs, PvP, fire, void, and more.

Works on **Paper 1.21+** (Spigot 1.21+ may work). Requires **Java 21**.

## Commands

- `/brainrot start` — enable custom death messages (requires `brainrot.admin`)
- `/brainrot stop` — disable custom death messages

## Build

```sh
./gradlew build
```

The plugin JAR is written to `build/libs/BrainrotDeathMessages-1.0.0.jar`.

## Install

Copy the built JAR into your server's `plugins/` folder and restart (or use a plugin manager).
